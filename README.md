# Simple Interest Calculator

## Description
A simple project explaining how to calculate simple interest.

## Formula
Simple Interest = (Principal x Rate x Time) / 100

## Example
- Principal: 1000
- Annual Interest Rate: 5%
- Time: 2 years
- Simple Interest: 100

## Calculation
(1000 x 5 x 2) / 100 = 100

## Usage
Enter the principal amount, annual interest rate, and time in years
into the formula to calculate simple interest.
